# 北京城市森林扰动—恢复韧性的遥感表征

项目主页（静态单页），用于介绍 2027 年大学生创新创业训练计划项目，并以逐环节对照的方式呈现**两版技术路线**。

> 不是问「碳汇有多少」，而是问「受扰之后，还能不能恢复」。

## 内容结构

| 章节 | 内容 |
|---|---|
| 01 项目概览 | 研究背景、变量定位、与静态碳核算的区别 |
| 02 科学问题 | RQ1 格局 / RQ2 机制 / RQ3 方法 |
| 03 技术路线 | **V1 原版** 与 **V2 重构版** 两套 7—8 步流水线，同页展示 |
| 04 两版对比 | 9 个维度的逐项差异 |
| 05 八条意见 | 导师意见 → 问题实质 → 重构回应 → 落点 |
| 06 复核发现 | 4 项来自本地栅格元数据的硬证据 |
| 07 指标体系 | RL / T90 / C10 / CI / RD / P(H) |
| 08 数据与参数 | 数据源清单 + LandTrendr 参数表 |
| 09 进度 | 2026.11 — 2027.11 五个阶段 |
| 10 团队 | 成员与分工 |

技术路线的每个环节都按统一六段式标注：**输入 → 用什么 → 怎么用 → 模型参数 → 输出 → 交给下一步**，保证上下游可追踪。

## 技术实现

- 纯静态：HTML + CSS + 原生 JavaScript，**零外部依赖**（无 CDN、无字体请求、无框架）。
- 所有图形由 CSS/SVG 绘制，不依赖位图资源，克隆即可完整显示。
- 支持：同页路线对照、滚动进度条、导航高亮、入场动效、`prefers-reduced-motion`、打印样式、移动端适配。

```bash
python -m http.server 8765

```

直接双击 `index.html` 也可浏览，但建议用本地服务器以获得一致的字体与滚动行为。

## 部署到 GitHub Pages

1. 将本目录内容推送到仓库默认分支（`main`）。
2. 仓库 **Settings → Pages**：
   - Source 选择 `Deploy from a branch`
   - Branch 选择 `main`，目录选 `/ (root)`
3. 等待约 1 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

仓库根目录已包含 `.nojekyll`，可避免 Jekyll 处理带来的路径问题。
