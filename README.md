# 扰动与恢复视角下北京市森林韧性的遥感表征

项目主页（静态单页），用于介绍 2027 年大学生创新创业训练计划项目，展示回应导师意见的**单条技术路线**。

> 从森林扰动出发，研究恢复过程和区域差异。

## 内容结构

项目以森林扰动状态、恢复韧性定义、指标构建和时空分析为主线。指标包括五年恢复过程指数、第五年恢复比例、恢复时间及再次扰动情况；结果须经独立核查和敏感性分析。

## 技术实现

- 纯静态：HTML + CSS + 原生 JavaScript，**零外部依赖**（无 CDN、无字体请求、无框架）。
- 所有图形由 CSS/SVG 绘制，不依赖位图资源，克隆即可完整显示。
- 支持：可展开的路线节点、滚动进度条、导航高亮、入场动效、`prefers-reduced-motion`、打印样式、移动端适配。

## 部署到 GitHub Pages

1. 将本目录内容推送到仓库默认分支（`main`）。
2. 仓库 **Settings → Pages**：
   - Source 选择 `Deploy from a branch`
   - Branch 选择 `main`，目录选 `/ (root)`
3. 等待约 1 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

仓库根目录已包含 `.nojekyll`，可避免 Jekyll 处理带来的路径问题。
